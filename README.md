**An open-source indexer thingy made in Rust with a clean user interface**

## What does ``grepthing`` have?

- **SUPER duper fast multithreading!:** Uses the `ignore` crate for speed! Perhaps you could say.. need for speed..
- **Verbose stuff:** Tracks what file/director has been scanned, elapsed time, and live throughput speed (files/s)
- **Ease of use:** Copy any matched patch to your clipboard by clicking the match!
- **Uses Rust:** Uses Rust.
- And much much more. Go see for yourself!

## ⚠ Please DO NOTE that 

- Pointing it to massive directories like `C:\` will go thru thousands of files per second. soo make sure your queries are accurate!
- Make sure your target path actually exists, or the query exists (atleast) so you don't waste your time!

## How do I use it?

- Click the Releases tab to use the tool! Or..

---

- Clone or download the repository
- Change to the project directory
- Run ```cargo build --release`` or ```cargo run``` for faster use
